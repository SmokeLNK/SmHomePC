# SmHomePC
# 🏠 Дом с Алисой PC  Легковесный и удобный Windows-клиент для управления Умным домом Яндекса прямо с рабочего стола.  ### ⚡ Главные особенности: - 💡 **Управление устройствами**: включение/выключение розеток, ламп, настройка яркости и цветовой температуры. - 📡 **Умные статусы**: «В сети / Не в сети» для датчиков, хабов и колонок; «Включено / Выключено» для управляемой техники. - 🗂️ **Комнаты с Drag & Drop**: гибкая сортировка и приоритет комнат простым перетаскиванием. - ▶️ **Сценарии Яндекса**: детальный просмотр условий, устройств и запуск в один клик. - 📜 **История событий**: фиксация кликов кнопок (одинарное/двойное/удержание), открытия дверей, датчиков протечки и движения с точным временем. - 🎨 **Темы**: фирменная тёмная и монохромная (чёрно-белая). - 📦 **Простая установка**: единый инсталлятор `.exe` без необходимости ставить дополнительные среды.
